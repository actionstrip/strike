# 운전대와 핸들을 잡는 기본 자세

사용자가 "이게 정상"이라고 고른 기준은 **Cruiser에 탄 로봇**이다. 얼굴 위치, 몸통 각도, 팔 위치를 다른 바이크와 자동차도 이것에 맞춘다(사용자: "cruiser 를 다시 봐바, 얼굴 위치와 몸통과, 팔의 위치가 이게 정상이야, 자동차에서도 마찬가지야").

## 공통 원칙

1. **몸통은 곧게.** 척추(Spine, Spine1, Spine2)는 Cruiser 첫 프레임의 방향을 쓴다. 방울의 등은 운전대 쪽으로 굽어 있어 그대로 쓰면 웅크려 보인다. 몸을 숙이거나 젖힐 때는 Spine 아래를 축으로 등 전체를 한 덩어리로 돌린다.
2. **머리는 정면.** 몸통을 어떻게 돌렸든 마지막에 목과 머리를 똑바로 세운다(`look_ahead`: 쉬는 자세 방향, 또는 `upright(['Neck','Head'])`: Cruiser 방향). 몸을 젖히면 고개가 들리고, 숙이면 고개가 땅을 본다.
3. **손은 실제로 잡는 곳에.** 방울의 손 위치는 방울이 짧은 팔을 뻗은 자리일 뿐이고 모든 차에서 같다. 차는 `Steering` 메시의 테두리, 바이크는 핸들 끝 손잡이를 잡는다. 손목(Hand 뼈 머리)은 잡을 곳에서 어깨 쪽으로 아래팔 길이의 0.3만큼 물린다. 손 메시가 그만큼 앞으로 뻗어 손바닥이 테두리에 온다.
4. **팔은 늘이지 않는다.** 팔 길이는 그대로 두고 two-bone IK로 놓는다. 닿지 않으면 몸을 숙이거나(자동차 15도, 바이크 `MAX_LEAN` 40도) 앞으로 민다. 팔을 늘이면 기계 부품이 벌어진다.
5. **팔꿈치는 바깥·아래·뒤, 무릎은 앞으로.** 굽는 방향은 `ELBOW_POINTS`(0.5, 0.6, -1, 좌우 대칭), `KNEE_POINTS`(0, -1, 0.4)로 고정한다. 방울의 팔은 거의 펴져 있어 굽는 면을 가져오면 팔꿈치가 뒤집힌다. 뼈의 쉬는 자세 경첩축도 그 면에 맞춘다.
6. **손목과 발목은 꺾지 않는다.** 아래팔 방향 그대로 둔다. 방울의 손 방향을 쓰면 비틀린 아래팔 때문에 손목이 반대로 꺾였다.
7. **얼굴은 손에서 떨어지게.** 머리 뼈 시작점에서 두 손 가운데까지가 위팔 길이의 `FACE_CLEAR`(1.6)배 이상(사용자: "핸들에서 얼굴이 떨어질 필요가 있어"). 머리 뼈 끝은 방울의 긴 머리 그대로라 쓰지 않는다.

## 자동차

- 등은 등받이에 닿고, 엉덩이는 방석 위 등받이 쪽 끝에 붙는다. 등받이 기울기를 그대로 따르면 엉덩이가 앞으로 빠져 누워 보이므로, 골반 뒤 틈이 없어질 때까지 등을 조금 세운다(cars.md의 `sit_back`).
- 손은 운전대 바깥 1/3, 가운데보다 조금 위(9시 15분~10시 10분 사이). 운전대 위쪽 끝을 잡으면 손가락이 위로 솟아 어색했다.
- 팔꿈치는 조금 굽는다. 다 펴지면 운전대가 먼 것이니 숙이거나 민다.
- 발은 페달 쪽 바닥에 놓는다. 무릎은 조금 굽힌 채(다리 길이 0.93) 방울의 다리 방향보다 아래(`LEG_DROP`)로 뻗고, 바닥보다 아래면 올린다.

## 오토바이, 쿼드

- 머리가 핸들보다 높은 바이크(Moto, Dirt, Quad, Cruiser)는 Cruiser 자세 그대로: 등은 약간 앞으로, 머리는 수평, 팔은 앞으로 뻗어 손잡이를 잡고 팔꿈치는 바깥으로 조금 굽힌다.
- 엉덩이는 좌석(빨간 면 같은 실제 좌석 재질) 위에, 뒤쪽까지 닿게.
- 발은 발판(peg) 위. 무릎은 앞으로 굽어 연료탱크 옆에 온다.

## 포탑 (Gunner)

- 서서 총 손잡이를 잡는다. 얼굴 거리는 보지 않는다(총을 겨누므로 얼굴이 총에 가깝다).
- 다리는 해치 안으로 뻗는다. 차체에 가려지므로 바닥 맞추기는 하지 않는다.

## 확인 목록 (렌더와 게임에서)

- [ ] 등이 등받이에 닿았나, 엉덩이가 방석/좌석 위에 닿았나(묻히지도 뜨지도 않게)
- [ ] 엉덩이가 등받이 쪽으로 당겨졌나(누운 자세가 아닌가)
- [ ] 몸통이 곧은가(웅크리지 않았나)
- [ ] 머리가 정면을 보나, 지붕과 앞유리를 뚫지 않나
- [ ] 두 손이 운전대 테두리/손잡이에 있나(`seat_check`의 `gap` 약 0.2)
- [ ] 팔꿈치가 바깥·아래로 굽었나, 손목이 꺾이지 않았나
- [ ] 발이 바닥이나 발판 위에 있나, 차체 밖으로 나오지 않았나(`OPAQUE=1` 렌더)
- [ ] 클립 동안 다리가 움직이지 않나(`travel`)
- [ ] 크기가 사용자가 말한 기준(Hunter 포탑의 로봇 크기가 기준이었다)과 맞나
