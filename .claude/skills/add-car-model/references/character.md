# 캐릭터 검토

새 차마다 이 순서대로 판단한다. 캐릭터는 모든 차가 함께 쓰므로 수정 범위가 넓다. 차 쪽 수정으로 해결되면 캐릭터는 건드리지 않는다.

## 구조

- 모델: `models/bangul_m.glb`, 원본: `3d/bangul_m_drive.blend`
- 뼈대: Mixamo 계열, 뼈 이름은 `mixamorig:Hips` 형식
- 클립: `Cruiser`, `Dirt`, `Drive`, `Gunner`, `Idle`, `Jump`, `Moto`, `Quad`, `Ride`, `Walk`
- `Kart`가 캐릭터를 `Seat`의 자식으로 붙이고 `ride`의 클립을 재생한다.
- 차 모델의 `carScale`(1.25)을 함께 받는다. `driverScale`은 차 기준 크기다.
- 운전자 시점에서는 캐릭터가 숨겨진다.
- 캐릭터는 `CHARACTERS`에 여럿 있다. 로봇(`models/robot.glb`, `3d/Robot_game.blend`)은 방울의 뼈대에 입힌 모델로, 플레이어가 고를 수 있고 AI 차량에도 탄다(`Seat`가 없는 Porsche는 빈 차로 달린다). 헬멧은 쓰지 않는다.
- **방울의 클립을 바꾸거나 새로 만들면 로봇도 다시 빌드한다.** `examples/robot_build.py`가 `bangul_m_drive.blend`의 클립마다 로봇 전용 클립을 새로 만든다. 새 클립 이름은 스크립트의 `CLIPS`, `HEIGHT`에 넣고, 발판에 발을 올리는 탈것이면 `PEG_FEET`에도 넣는다.
- 로봇 클립 만드는 방식: 방울의 엉덩이 위치와 척추·머리 각도만 가져오고, 방울 클립의 뼈 늘이기(팔 최대 2.8배, 허벅지 3.6배)와 머리 줄이기(0.46~0.76배)는 버린다. 그대로 쓰면 로봇의 팔다리가 늘어나 바닥을 뚫고 머리가 작아진다. 로봇 크기는 엉덩이 위 높이를 방울의 `HEIGHT`배로 맞춘다(자동차 1.39, Moto 1.02, Gunner 0.85, Cruiser·Quad 1.13, Dirt 0.9). 사용자는 Hunter 포탑의 크기(0.85)를 기준으로 "덩치가 작다"고 했고, 2배는 너무 크다며 약 1.5배를 원했다. 자동차는 처음 1.16이었고 사용자가 1.2배 더 키우라고 해서 1.39다(지붕은 차별 클립에서 맞춘다). Moto는 정강이가 차체 아래로 빠져나오지 않는 1.02에서 멈췄다. 팔은 IK로 방울의 손 위치(운전대, 핸들, 총 손잡이)에 닿게 하고, 다리는 바이크면 방울의 발 위치(발판)로, 자동차와 포탑이면 방울 다리 방향보다 `LEG_DROP`만큼 아래로 뻗는다.
- 로봇의 체형과 관절: 로봇은 방울보다 가늘어서 부품마다 뼈와 수직 방향으로 키운다(`BULK_DEFAULT` 1.4, 손발 1.3, 머리 `BULK_HEAD` 1.3). 뼈 방향으로는 키우지 않아 관절이 벌어지지 않는다. IK의 굽는 방향은 방울에서 가져오지 않는다. 방울의 팔은 거의 펴져 있어 굽는 면이 정해지지 않아 팔꿈치가 뒤집혔다. 대신 팔꿈치는 `ELBOW_POINTS`(바깥·아래·뒤), 무릎은 `KNEE_POINTS`(앞)로 고정하고, 뼈의 쉬는 자세 경첩축을 그 면에 맞춘다. 손목과 발목은 꺾지 않는다. 방울의 손 방향을 그대로 쓰면 로봇의 비틀린 팔뚝 때문에 손목이 반대로 꺾였다.
- 척추 각도는 방울에서 조금씩 바꾼다. 손이 운전대에 닿지 않으면 팔을 늘이지 않고 앞으로 숙이고(`MAX_LEAN` 40도), 얼굴이 손에 너무 가까우면 뒤로 세운다(`MAX_BACK` 30도). 얼굴 거리는 머리 뼈의 시작점에서 두 손 가운데까지를 위팔 길이로 나눈 값이며 `FACE_CLEAR` 1.6 이상이 목표다(사용자: "핸들에서 얼굴이 떨어질 필요가 있어"). 머리 뼈의 끝은 방울의 긴 머리 뼈 그대로라 쓰지 않는다. Gunner는 총을 겨누므로 얼굴 거리를 보지 않는다.
- 머리가 핸들보다 높은 바이크(Moto, Dirt, Quad, `UPRIGHT`)는 사용자가 정석이라고 고른 Cruiser 자세를 따른다. Cruiser 첫 프레임의 엉덩이, 척추, 목, 머리 방향(아마추어 기준)을 그대로 쓰고 팔다리만 IK로 각 바이크의 핸들과 발판에 맞춘다. 그래서 `CLIPS`에서 Cruiser가 이들보다 먼저 와야 한다. 이 바이크들은 얼굴 거리를 보지 않는다. 얼굴 거리 때문에 척추를 세우면 Cruiser보다 몸이 서서 다른 자세가 된다.
- 방울은 바이크 차체에 엉덩이가 묻혀 있었다. 로봇은 `HIP_SHIFT`로 엉덩이를 좌석 위로 올린다. 사용자는 Moto의 탱크 뒤 빨간 좌석에 앉히라고 해서 Moto는 뒤로도 옮겼다. 값은 게임에서 잰다. 모델 그룹 좌표에서 Hips 가중치 정점의 가장 낮은 점을 찾고, 그 범위에서 아래로 광선을 쏴 좌석 윗면을 구한다. 이때 운전자는 잠시 떼어 둔다. 그 차이를 운전자 그룹 좌표로 바꾸면 Blender 단위(x, -z, y)가 된다. 가장 낮은 점만 맞추면 안 된다. 허벅지가 기울어 앞쪽만 좌석에 닿고 엉덩이 뒤쪽이 떠 보였다(사용자: "엉덩이가 떠있어"). 좌석 재질(moto `dark`, cruiser `leather`, enduro `black`, mantis `mantis`)에 맞는 광선만 골라 앞뒤 구간마다 틈을 보고, 뒤쪽 구간이 닿을 때까지 내린다. 허벅지 앞쪽이 좌석에 조금 묻히는 것은 괜찮다.
- 자동차는 차마다 `Drive.<차 id>` 클립을 따로 만든다(`DRIVE_CARS`, 게임은 `Driver.play(ride, carId)`에서 있으면 그것을 재생한다). 차 glb를 `Seat` 기준, `driverScale`로 나눈 로봇 좌표로 읽어 BVH로 잰다. 사용자 요청은 "등받이에 맞춰서 엉덩이와 등을 뒤로 빼고, 핸들을 잡게, 머리는 정면"이었다. 순서는 다음과 같다.
  1. 척추를 Cruiser의 곧은 등으로 바꾼다(방울의 등은 운전대 쪽으로 굽어 있다).
  2. 엉덩이 뒤에서 높이별로 뒤쪽으로 광선을 쏴 등받이 기울기를 구하고(5~35도), 등을 그 각도로 젖힌다. 목과 머리는 쉬는 자세로 되돌려 정면을 본다.
  3. `settle`: 엉덩이 정점에서 아래로, 척추 정점에서 뒤로 광선을 쏴 방석과 등받이에 닿게 옮긴다. 아래 광선은 거의 수평인 면(`normal.z` 0.7 초과)만 센다. 기울어진 등받이 아래에 있는 엉덩이 뒤쪽 정점까지 세면 로봇이 좌석 위로 떠올랐다(Corsa).
  4. 머리가 지붕을 뚫으면 Hips 배율을 줄인다(`fit_roof`).
  5. 손은 방울의 손 위치가 아니라 차의 `Steering` 메시 테두리(좌우 바깥 1/3, 가운데보다 조금 위)를 잡는다. 방울의 손 위치는 모든 차에서 같아서 운전대가 먼 차(Barchetta, Vortex, Cuneo)에서는 허공을 잡았다. 손이 닿지 않으면 15도까지 숙이고, 그래도 안 되면 앞으로 민다.
  3-1. `sit_back`: 골반 위쪽 뒤로 광선을 쏴 등받이와 틈이 있으면 등을 3도씩 세우고 다시 앉힌다(최대 24도). 등받이 기울기만 따르면 엉덩이가 앞으로 빠져 누운 것처럼 보였다(사용자: "엉덩이를 앞으로 빼고 누워있는것 처럼 보여"). 골반 아래쪽은 버킷 시트 곡면에 늘 닿으므로 Hips 관절보다 위의 정점만 쓴다.
  6. 발은 바닥 위에 세운다. 바닥 광선은 엉덩이 높이에서 아래로 쏜다. 발 위에서 쏘면 대시보드를 바닥으로 읽어 발이 들렸다(Racer). 발 위치는 첫 프레임 값으로 고정한다. 프레임마다 바닥 광선이 다른 면에 맞아 Senna와 F1의 발이 0.4씩 오르내려 하체가 움직이는 것처럼 보였다.
  - `CAR_SIZE`로 차마다 더 키운다(Barchetta, Vortex 1.2, Cuneo 1.4, Titan 1.4). 지붕에 닿으면 `fit_roof`가 다시 줄이므로 실제 배율은 결과의 `size`를 본다. Titan처럼 `Gunner`를 쓰는 차는 `GUNNER_CARS`에 넣으면 `Gunner.<차 id>` 클립이 따로 생긴다.
  - Cuneo는 좌석이 긴 경사로 이어진 레이싱 시트라 광선이 위쪽 세운 부분만 등받이로 읽는다. `RECLINE_FIX`로 45도를 주고 뒤로 밀지 않으며 `sit_back`도 하지 않는다. 그러지 않으면 경사를 타고 올라가거나 몸이 서서 머리가 지붕을 뚫었다. 그래도 1.4배는 지붕에 닿아 1.25배까지만 커진다.
  - 확인은 scratchpad에서 차 glb를 같은 좌표로 불러와 x-ray 측면 렌더로 본다(등받이, 방석, 운전대, 바닥, 지붕).
- 로봇 빌드에서 겪은 함정: 아마추어 오브젝트에 배율을 주면 내보낸 스킨이 엉뚱한 곳에 그려진다(그래서 Hips 뼈에 배율을 키로 넣는다). glTF 클립은 모든 뼈의 위치를 절대값으로 담는다. 게임에서 정점 위치를 잴 때는 `skeleton.update()`를 먼저 부른다. 브라우저에서 같은 값의 트랙들은 값 배열을 공유하므로 트랙 값을 직접 고치면 다른 뼈까지 바뀐다.
- `Driver`는 `CARS`에 쓰인 클립만 준비한다. 없는 이름을 쓰면 `[driver] X clip is missing` 오류가 난다.

## 판단 순서

```
맞는 자세의 클립이 있는가?
├─ 있다 → 크기가 맞는가?
│         ├─ 아니다 → driverScale만 다른 CarRide를 추가
│         └─ 맞다  → 몸이 좌석에 맞는가?
│                    ├─ 아니다 → Seat 이동, 방석 추가
│                    └─ 맞다  → 손이 맞는가?
│                               ├─ 아니다 → Steering 이동, 축소, 기둥 추가
│                               └─ 맞다  → 수정 없음
└─ 없다 → 새 클립 제작 (사용자에게 알린 뒤)
```

## 클립 선택

| 차 종류 | 클립 | 기존 설정 | `driverScale` |
|---|---|---|---|
| 일반 승용, 스포츠카 | `Drive` | `CAR_RIDE` | 0.4 |
| 지프, SUV | `Drive` | `JEEP_RIDE` | 0.5 |
| 스포츠 바이크 | `Moto` | `BIKE_RIDE` | 0.98 |
| 크루저 바이크 | `Cruiser` | `CRUISER_RIDE` | 1.1 |
| 오프로드 바이크 | `Dirt` | `DIRT_RIDE` | 0.98 |
| 사륜 바이크, 버기 | `Quad` | `QUAD_RIDE` | 0.98 |
| 서서 쏘는 차 | `Gunner` | `GUNNER_RIDE` | 1.3 |

`lean`은 조향 때 기울기(음수는 안쪽), `steerTurn`은 운전대 회전량이다. 네 바퀴 차는 -0.06과 1.3이고, 바이크는 몸을 많이 기울이고 핸들은 적게 돌린다.

`Gunner`는 머리를 0.46배로 줄여 놓은 클립이다. 전체 크기가 크기 때문이며, 다른 차에 쓰면 머리 비율이 달라 보일 수 있다.

## 자리 잡기 수치

`Drive` 클립, `driverScale` 0.4일 때 `Seat` 기준 값이다. `driverScale`에 비례한다.

| 부위 | 앞 | 위 |
|---|---|---|
| 손 | 0.21 | 0.2~0.26 |
| 눈 | 0 | 0.62~0.72 |

0.5면 손은 앞 0.26, 위 0.3 근처이고 눈은 위 0.85 근처다.

**이 값은 시작점이다.** 캐릭터가 머리와 몸이 큰 형태라 운전대를 손 위치에 그대로 두면 몸과 겹친다. Scout에서 사용자가 지적해 앞으로 0.42까지 옮겼다. 측면에서 운전대와 몸 사이에 틈이 보이는지 확인한다.

## 문제별 처리

| 증상 | 처리 |
|---|---|
| 몸이 공중에 뜸, 좌석이 등받이뿐 | 상자로 방석을 만들고 `Seat`를 그 위로 |
| 다리가 차체를 뚫음 | `Seat`를 올리거나 뒤로, `driverScale` 축소 |
| 머리가 지붕을 뚫음 | `Seat`를 낮추거나 `driverScale` 축소 |
| 운전대 없음 | 토러스로 제작, 면은 앞뒤 축에 수직. 기둥은 차체에 |
| 운전대가 몸과 겹침 | 앞으로 이동, 기둥으로 대시보드까지 연결 |
| 운전대가 멀어 손이 안 닿아 보임 | 틈이 작으면 둔다. 크면 운전대를 키우거나 `driverScale`을 올림 |
| 운전석이 오른쪽 | `Seat`, `Steering`을 `-X`로 |
| 지붕 있는 차에서 안 보임 | 창이 불투명하지 않은지, 유리가 `glass` 재질인지 확인 |

`Steering`은 `rotation.z`로 돌아간다. 운전대를 기울여 만들면 돌 때 흔들리므로 메시에 기울기를 넣지 않는다. 기울여야 하면 코드 수정이 필요하다.

## `Eye`

- 위치는 모델의 빈 노드, 내려다보는 각도는 `CARS`의 `eyePitch`(일반 차 -0.08~-0.16, 바이크 -0.2)다.
- 머리에 맞출 필요가 없다. 캐릭터가 숨겨지기 때문이다.
- 운전대가 화면 아래로 빠지면 `Eye`를 뒤로 옮긴다. Scout는 0.3 뒤로 옮겼다.
- 대시보드가 시야를 막으면 올린다.
- 운전대가 시야를 많이 가리면 낮추거나 줄인다.

## 새 클립 만들기

`Moto`, `Cruiser`, `Quad`, `Gunner`, `Dirt`를 이 방식으로 만들었다. `examples/gunner_pose.py`, `examples/gunner_save.py`, `examples/dirt_pose.py`가 실제 스크립트다.

1. `3d/bangul_m_drive.blend`를 연다.
2. 새 차의 `Seat` 좌표, `driverScale`, 손과 발이 닿을 지점을 차 모델 좌표로 재서 스크립트 상단에 적는다.
3. 뼈대를 기본 자세로 되돌리고, 엉덩이를 옮기고, 척추를 조금씩 돌린다.
4. `limb()`로 팔과 다리를 목표 지점까지 뻗는다. 거리가 모자라면 뼈 길이를 늘린다.
5. 발 방향을 맞춘다.
6. 프레임 1, 25, 49에 키를 넣고, 가운데 프레임에만 엉덩이를 살짝 움직여 숨 쉬는 효과를 준다. 첫 프레임과 끝 프레임이 같아야 루프가 끊기지 않는다.
7. 활성 Action을 `Drive`로 되돌리고 저장한다.
8. 아래 설정으로 내보낸다. 차 내보내기와 설정이 다르다.

```python
bpy.ops.export_scene.gltf(filepath=out, export_format='GLB', use_selection=False, export_yup=True, export_apply=False,
                          export_animations=True, export_animation_mode='ACTIONS', export_cameras=False, export_lights=False,
                          export_skins=True, export_morph=False)
```

9. `CarRide`에 클립 이름을 넣는다. 코드 수정은 더 필요 없다.

### 주의

- Blender 5의 Action은 슬롯이 필요하다. 새 Action에 슬롯을 만들고 `action_slot`을 지정한다.
- 차 모델을 불러와 캐릭터와 함께 렌더하면 손과 발이 맞는지 바로 보인다. `examples/mview.py`의 `side`, `front`, `view`를 쓴다.
- 다른 차의 클립을 복제해 쓸 때도 그 차의 손잡이 좌표를 새로 잰다.
- 저장 파일에 기존 Action이 전부 남아 있는지 `bpy.data.actions`로 확인한다. `use_fake_user`를 켜 둔다.
- **캐릭터 파일을 바꾸면 모든 차를 다시 확인한다.** 차를 하나씩 골라 자세, 머리 크기, 손 위치를 본다.
- 파일 크기를 본다. 지금 `bangul_m.glb`는 약 800KB다.

## 헬멧

- 헬멧은 `CARS`의 `helmets`로 차마다 정한다. 첫 번째가 기본값이고, 선택도 차마다 저장한다. 모델 목록은 `HELMETS`다.
- `examples/helmet_*_build.py`가 실제 스크립트다. 정점을 캐릭터 기본 자세 좌표에 두고 코드가 머리 뼈에 붙인다.
- 얼굴을 덮는 헬멧은 `hides`로 머리카락과 안경을 숨기고, 얼굴이 드러나는 헬멧은 `hairCut`으로 윗머리만 자른다.
- 헬멧 색은 텍스처에 구워져 있어 `HelmetPaint`가 픽셀을 다시 칠한다. `HELMETS`의 `paint`로 바꿀 영역을 정한다(`hue`와 `width`, 또는 `rect`).
- **`bangul_m.glb`를 Blender로 불러와 렌더하면 머리가 작게 나온다.** 머리를 줄인 클립의 자세가 남기 때문이다. 메시 정점 값은 믿어도 되지만, 머리에 맞는지는 게임 화면에서 판단한다. 클립의 머리 크기가 달라도 헬멧은 뼈를 따라 함께 커진다.

## 확인 항목

- [ ] 측면에서 좌석에 앉아 있다
- [ ] 정면에서 좌우 중심이 좌석과 맞는다
- [ ] 다리와 몸이 차체를 뚫지 않는다
- [ ] 운전대와 몸 사이에 틈이 있다
- [ ] 손이 운전대나 손잡이 근처에 있다
- [ ] 조향 때 운전대가 돌고 몸이 기운다
- [ ] 주행 애니메이션이 끊기지 않는다
- [ ] 운전자 시점에 캐릭터가 나타나지 않는다
- [ ] 차를 바꾸면 자세와 크기가 그 차에 맞게 바뀐다
- [ ] 스핀, 점프, 리스폰 뒤에도 자리를 벗어나지 않는다
